Embedded Firmware Highlights

  • Deterministic Scheduler: Fixed-rate 30ms (33.3 Hz) timing using micros() without blocking delays.
  • Optimized Ultrasonic Timeout: Clamped pulseIn() to 5000 µs (~85 cm range) to prevent CPU starvation on acoustic dropouts.
  • Derivative on Measurement: Uses -dy/dt to totally eliminate actuator kick during setpoint step transitions.
  • Conditional Anti-Windup: Freezes integration when servo output saturates at physical endpoints ($25^\circ / 155^\circ$).
  • Zero Dynamic Allocation: Strictly avoids Arduino String objects to eliminate SRAM memory fragmentation on ATmega328P.

100-Mark Viva Theoretical Defense Notes

Core mathematical derivations and physical system constants used across simulation and hardware.

1. Double Integrator Plant Model

For a solid rolling sphere ($J = \frac{2}{5}m r^2$) on a beam tilted by angle $\alpha$:

(1 + 2/5) d²x/dt² = g · sin(α) ⇒ d²x/dt² = (5/7) g · α(t)

With kinematic linkage ratio $K_{\text{linkage}} = \frac{r_{\text{arm}}}{L_{\text{linkage}}} = \frac{2.0\text{ cm}}{14.0\text{ cm}} \approx 0.1429^\circ/^\circ$:

G_p(s) = X(s) / Θ(s) = 1.747 / s² (cm/s² per degree)

2. Routh-Hurwitz Stability Boundary

Closed-loop characteristic equation with PID controller:

s³ + K_plant·Kd·s² + K_plant·Kp·s + K_plant·Ki = 0

For all poles to lie in the Left Half-Plane (LHP):

Ki < K_plant · Kp · Kd ⇒ Ki < 1.747 × 2.40 × 0.90 = 3.77

Our operating gain $K_i = 0.04$ is well within this safe margin, providing high robustness against actuator lag.
